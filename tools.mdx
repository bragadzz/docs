## Para agentes de IA

Dê ao Claude Code, ao Cursor ou a qualquer outro agente o contexto da Cube. É tudo público e nada disso dá acesso à sua conta; para o agente agir nos seus projetos, use o [MCP da sua conta](#servidor-mcp-da-sua-conta), com uma chave de API.

| Recurso | Endereço em `docs.cubehosting.com.br` |
| --- | --- |
| Servidor MCP da documentação | `/mcp`, no seu cliente MCP ([como conectar](#conectar-o-servidor-mcp)) |
| Índice, com uma linha sobre cada página | [`/llms.txt`](https://docs.cubehosting.com.br/llms.txt) |
| A documentação inteira num arquivo só (uma página nova leva até 1 dia para entrar nele) | [`/llms-full.txt`](https://docs.cubehosting.com.br/llms-full.txt) |
| OpenAPI 3.1 da API pública | [`/api-reference/openapi.json`](https://docs.cubehosting.com.br/api-reference/openapi.json) |
| Qualquer página em Markdown | acrescente `.md` ao endereço, como [`/quickstart.md`](https://docs.cubehosting.com.br/quickstart.md) |

No painel, **Copiar contexto para o agente** copia um resumo em Markdown com esses endereços e a API, pronto para colar no chat. Ele não leva nenhuma chave nem dado da sua conta.

### Conectar o servidor MCP

O agente busca e lê a documentação pública quando precisa. Não acessa a sua conta nem os seus projetos.

<CodeGroup>
```bash Claude Code
claude mcp add --transport http cube-hosting-docs https://docs.cubehosting.com.br/mcp
```

```json Cursor e outros
{
  "mcpServers": {
    "cube-hosting-docs": {
      "url": "https://docs.cubehosting.com.br/mcp"
    }
  }
}
```
</CodeGroup>

No Cursor, o JSON vai em `~/.cursor/mcp.json` (ou em `.cursor/mcp.json` no projeto). Em outro editor, use o mesmo endereço na configuração de MCP dele.

### Servidor MCP da sua conta

Com uma [chave de API](https://app.cubehosting.com.br/api-keys), o agente vê os seus projetos, os logs e as métricas e, com uma chave de leitura e escrita, inicia, para e reinicia. Com as mesmas regras de [Cube AI](/cube-ai): nunca apaga nada, não mexe em arquivos e não vê o valor das variáveis. Guia completo em [MCP da sua conta](/account-mcp).

<CodeGroup>
```bash Claude Code
claude mcp add --transport http cube-hosting https://app.cubehosting.com.br/api/mcp --header "Authorization: Bearer $CUBE_API_KEY"
```

```json Cursor e outros
{
  "mcpServers": {
    "cube-hosting": {
      "url": "https://app.cubehosting.com.br/api/mcp",
      "headers": {
        "Authorization": "Bearer ${env:CUBE_API_KEY}"
      }
    }
  }
}
```
</CodeGroup>

Antes, guarde a chave na variável `CUBE_API_KEY` (`export CUBE_API_KEY=cube_…`). No Cursor, o `${env:CUBE_API_KEY}` lê a chave dessa variável, fora do arquivo.
