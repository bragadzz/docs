---
title: "Pedir o link temporário"
openapi: "POST /blob/objects/{id}/download-url"
description: "Um link curto que vence, para abrir ou baixar um arquivo público ou privado, sem a chave."
---

O link tem o nosso domínio e o nome do arquivo no fim, como `https://cdn.cubehost.dev/s/q7Rf2kLm9xA1.tm3a9k.9ig4z3Rd7w4dd7wb/relatorio.pdf`. Vale 5 minutos por padrão (até 1 hora com `expiresInSeconds`) e só abre esse arquivo: depois do prazo, ou com qualquer parte do token mudada, responde `403`. Ele pode ir para quem precisa do arquivo, como um usuário do seu bot, sem expor a chave.

A imagem (PNG, JPEG, GIF, WebP, AVIF, BMP) abre no navegador; o resto baixa como anexo, com o nome do arquivo. Com `?download=1` no fim do link, até a imagem baixa. HTML, SVG, XML e JavaScript sempre saem como binário: um link do Blob nunca vira página aberta.

<Note>
  Para um link que **não vence**, torne o arquivo público em [Tornar público ou privado](/api-reference/blob/update) e use o `publicUrl`.
</Note>

<Tip>
  Precisa entregar o mesmo arquivo de novo depois do prazo? Peça outro link: cada pedido é rápido e fica na Atividade da conta.
</Tip>

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`not_found`](/errors#param-not-found) | 404 | Confira o `id`: arquivo de outra conta ou envio não confirmado também dão 404. |
| [`invalid_request`](/errors#param-invalid-request) | 400 | `expiresInSeconds` vai de 60 a 3600. |
| [`account_suspended_manually`](/errors#param-account-suspended-manually) | 409 | A conta foi [suspensa pela equipe](/security#suspensão-pela-equipe): enquanto isso, o link temporário sai só pelo painel, com 5 minutos. Fale com o suporte no Discord. |
| [`blob_unavailable`](/errors#param-blob-unavailable) | 503 | Tente de novo em instantes. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
