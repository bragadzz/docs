---
title: "Escrever um arquivo"
openapi: "PUT /projects/{id}/files/content"
description: "Grave um arquivo de texto no projeto."
playground: "simple"
---

Grava um arquivo de texto (até 1 MB), por cima do que existe ou só se for novo (`isNew`). Depois, [aplique as mudanças](/api-reference/projects/apply) para valer no projeto no ar.

Permissão da chave: `files:write` ([Chaves de API](/api-keys)).

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`insufficient_scope`](/errors#param-insufficient-scope) | 403 | A chave não tem a permissão da rota (`requiredScope` diz qual): marque em Chaves de API › Editar permissões. |
| [`invalid_path`](/errors#param-invalid-path) | 400 | O caminho precisa ficar dentro do projeto, sem `..`, `/` no começo nem `\`. |
| [`invalid_request`](/errors#param-invalid-request) | 400 | Confira o corpo ou os parâmetros do pedido. |
| [`file_protected`](/errors#param-file-protected) | 403 | Dentro da pasta das dependências é só leitura: mude o manifesto e aplique, ou apague a pasta inteira. |
| [`files_not_allowed`](/errors#param-files-not-allowed) | 403 | O Free não tem os arquivos do projeto: mude para um plano pago. |
| [`file_already_exists`](/errors#param-file-already-exists) | 409 | Escolha outro nome, ou mande `shouldOverwrite: true`. |
| [`project_busy`](/errors#param-project-busy) | 409 | Espere o envio ou a instalação em curso terminar. |
| [`special_file`](/errors#param-special-file) | 422 | É um atalho ou arquivo especial: troque pelo arquivo de verdade. |
| [`disk_full`](/errors#param-disk-full) | 507 | O disco do projeto encheu. Apague arquivos que ele não usa e tente de novo, ou mude para um plano com mais [disco por projeto](/account/plans#disco-por-projeto). |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
