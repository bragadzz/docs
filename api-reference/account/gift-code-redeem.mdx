---
title: "Resgatar código de presente"
openapi: "POST /account/gift-codes/redeem"
description: "Resgata um código de presente na conta da chave."
---

Resgata o código na sua conta e devolve o que ele fez (`gift`) e a conta com o plano de agora (`account`). Cada código vale uma vez, e a conta tem um presente por vez. Pede uma chave de **leitura e escrita** criada na própria conta: a de uma equipe não resgata. Veja antes com a [Prévia](/api-reference/account/gift-code-preview); as regras estão em [Códigos de presente](/account/gift-codes).

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`invalid_gift_code`](/errors#param-invalid-gift-code) | 400 | Confira o código: a resposta é a mesma para um código que não existe. |
| [`gift_code_used`](/errors#param-gift-code-used) | 410 | Cada código vale uma vez: peça outro a quem deu o presente. |
| [`gift_code_expired`](/errors#param-gift-code-expired) | 410 | O prazo de resgate acabou: peça outro código. |
| [`gift_already_active`](/errors#param-gift-already-active) | 409 | A conta já tem um presente: resgate depois da data na `message`. |
| [`plan_without_cycle`](/errors#param-plan-without-cycle) | 409 | O plano liberado não tem vencimento: só um código de plano maior vale. |
| [`api_key_not_allowed`](/errors#param-api-key-not-allowed) | 403 | Use uma chave criada na sua conta, não numa equipe. |
| [`too_many_attempts`](/errors#param-too-many-attempts) | 429 | Espere o `Retry-After`: são 10 tentativas a cada 15 minutos. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
