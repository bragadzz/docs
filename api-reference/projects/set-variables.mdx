playground: "simple"

Troca a lista inteira de variáveis do projeto numa chamada só.

<Warning>
  **A lista que você manda substitui a que está guardada.** Variável que ficar de fora é apagada, e valor apagado não volta. Para mudar uma só, mande todas: a que muda com `value` e as outras só com `name`, para manter o valor. Veja os nomes atuais em [Listar variáveis](/api-reference/projects/list-variables).
</Warning>

<CodeGroup>
```json Novo TOKEN, mantendo o PREFIX
{
  "variables": [
    { "name": "TOKEN", "value": "token-novo" },
    { "name": "PREFIX" }
  ]
}
```

```json Apagar todas
{
  "variables": []
}
```
</CodeGroup>

No primeiro exemplo, `TOKEN` recebe um valor novo, `PREFIX` mantém o valor que já tinha e qualquer outra variável é apagada.

<Tip>
  Se `isRestartRequired` vier `true`, [reinicie](/api-reference/projects/restart) o projeto para ele receber os valores novos.
</Tip>

Veja as regras de nomes e tamanhos em [Variáveis de ambiente](/hosting/environment-variables#regras).
