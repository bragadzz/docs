---
title: "Listar variáveis"
openapi: "GET /projects/{id}/variables"
description: "Os nomes das variáveis de ambiente do projeto. Os valores nunca voltam."
---

Devolve só os **nomes** das variáveis de ambiente. Os valores ficam cifrados e nunca voltam, nem pelo painel.

<Note>
  Mesmo sendo uma leitura, esta rota pede uma chave de **leitura e escrita**: saber quais segredos um projeto usa já é informação sensível.
</Note>

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`insufficient_permission`](/errors#param-insufficient-permission) | 403 | Use uma chave de leitura e escrita, mesmo para listar. |
| [`variables_unavailable`](/errors#param-variables-unavailable) | 503 | Tente de novo em instantes. |
| [`not_found`](/errors#param-not-found) | 404 | Confira o ID do projeto. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
