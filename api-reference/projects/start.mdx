---
title: "Iniciar um projeto"
openapi: "POST /projects/{id}/start"
description: "Ligue um projeto. A resposta chega quando ele está de pé."
playground: "simple"
---

Liga o projeto e responde quando ele está de pé. Se ele já estava no ar, nada muda.

- Só sobe o que cabe no plano: a memória deste projeto mais a dos que já estão ligados não pode passar a do plano (`plan_limit_reached`).
- Se a última instalação falhou, envie o código de novo antes (`install_pending`).
- Projeto de [template](/hosting/templates) sem uma variável obrigatória dele, como o `DISCORD_TOKEN`, não sobe (`missing_variables`, com os nomes em `missingVariables`): [defina a variável](/api-reference/projects/set-variables) antes.
- Se a pasta das dependências (`node_modules`, ou a `vendor` do PHP) foi [apagada pela aba Arquivos](/hosting/files#apagar-a-pasta-das-dependências), ou se a versão da linguagem, o arquivo principal ou o comando de instalação mudaram em **Configurações**, o projeto passa pela instalação antes de subir e a resposta é `202`. Com a pasta no lugar e nada mudado, ele só sobe, sem instalar.

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`install_pending`](/errors#param-install-pending) | 409 | A última instalação falhou: corrija e envie o código de novo. |
| [`missing_variables`](/errors#param-missing-variables) | 409 | Projeto de template sem a variável obrigatória (`missingVariables`): defina e inicie de novo. |
| [`plan_limit_reached`](/errors#param-plan-limit-reached) | 422 | Pare outro projeto ou diminua a memória deste. |
| [`project_busy`](/errors#param-project-busy) | 409 | Espere a ação em curso terminar. |
| [`account_suspended`](/errors#param-account-suspended) | 409 | Pague a renovação em Plano e cobrança. |
| [`free_slot_lost`](/errors#param-free-slot-lost) | 409 | A vaga do Free acabou pela meta: assine um plano para ligar de novo. |
| [`site_not_allowed`](/errors#param-site-not-allowed) | 403 | Sites são dos planos pagos. |
| [`variables_unavailable`](/errors#param-variables-unavailable) | 503 | Tente de novo em instantes. Nada foi alterado. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
