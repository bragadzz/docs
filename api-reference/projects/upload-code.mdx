Atualiza o código de um projeto que já existe, como faria um deploy no CI. A configuração do projeto não muda.

<Warning>
  O `.zip` novo substitui a pasta inteira do projeto (só as dependências instaladas ficam). Arquivos que o seu app criou, como um banco SQLite, somem se não estiverem no `.zip`.
</Warning>

## Deploy a cada push (GitHub Actions)

O jeito mais simples é o [workflow com a CLI cube](/github-actions): ele respeita o `.gitignore` e o `.cubeignore`, confere o limite do plano e espera a instalação. Só com `curl`, guarde a chave com a permissão `projects:deploy` como segredo `CUBE_API_KEY` e o ID do projeto como variável `CUBE_PROJECT_ID`:

```yaml .github/workflows/deploy.yml
name: Deploy na Cube
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Compactar
        run: zip -r projeto.zip . -x "node_modules/*" ".git/*" ".github/*"
      - name: Enviar
        run: |
          curl --fail-with-body \
            https://app.cubehosting.com.br/api/projects/${{ vars.CUBE_PROJECT_ID }}/code \
            -H "Authorization: Bearer ${{ secrets.CUBE_API_KEY }}" \
            -F "file=@projeto.zip"
```

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`invalid_zip`](/errors#param-invalid-zip) | 413 ou 422 | Diminua o `.zip` ou compacte de novo, sem senha. |
| [`unsafe_zip`](/errors#param-unsafe-zip) | 422 | Compacte só os arquivos do projeto, sem atalhos. |
| [`project_busy`](/errors#param-project-busy) | 409 | Espere a instalação ou a ação em curso terminar. |
| [`account_suspended`](/errors#param-account-suspended) | 409 | Pague a renovação em Plano e cobrança. |
| [`free_slot_lost`](/errors#param-free-slot-lost) | 409 | A vaga do Free acabou pela meta: assine um plano para ligar de novo. |
| [`insufficient_scope`](/errors#param-insufficient-scope) | 403 | A chave não tem a permissão da rota (`requiredScope` diz qual): marque em Chaves de API › Editar permissões. |
| [`too_many_requests`](/errors#param-too-many-requests) | 429 | Espere o `Retry-After`: um envio a cada 3 segundos. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
