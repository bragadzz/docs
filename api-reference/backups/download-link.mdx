---
title: "Pedir o link de download"
openapi: "POST /projects/{id}/backups/{backupId}/download"
description: "Um link de 5 minutos para baixar o backup em .zip."
---

O link vale 5 minutos e só com a mesma chave, que precisa ser de **leitura e escrita**: o `.zip` traz todos os arquivos do projeto, inclusive o `.env`. Use em seguida com [Baixar o backup](/api-reference/backups/download).
