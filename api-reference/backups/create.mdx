---
title: "Fazer backup"
openapi: "POST /projects/{id}/backups"
description: "Pede uma cópia dos arquivos do projeto agora."
---

O backup entra na fila e fica `ready` em alguns segundos. Consulte [Listar backups](/api-reference/backups/list) até ele sair de `pending`/`creating`. Quando o histórico está cheio, o backup mais antigo sai assim que o novo fica pronto.

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`backup_in_progress`](/errors#param-backup-in-progress) | 409 | Espere o backup atual ficar pronto. |
| [`project_busy`](/errors#param-project-busy) | 409 | Espere o envio ou a instalação terminar. |
| [`insufficient_permission`](/errors#param-insufficient-permission) | 403 | Use uma chave de leitura e escrita. |
| [`backups_unavailable`](/errors#param-backups-unavailable) | 503 | Tente de novo em instantes. Nada foi alterado. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
