title: "Listar backups"
openapi: "GET /projects/{id}/backups"
description: "Os backups do projeto, do mais novo, com o limite do plano."
---

Os backups do projeto e as regras do plano: quantos ficam guardados (`limit`), por quantos dias (`retentionDays`) e se o backup automático está ligado. Guia completo em [Backups](/hosting/backups).
