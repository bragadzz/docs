---
title: "Listar os backups da conta"
openapi: "GET /account/backups"
description: "Os backups de todos os projetos, também os de um projeto apagado, e os dos bancos excluídos."
---

Excluir um projeto não apaga os backups dele: eles ficam aqui com `isDeleted: true` até vencer (30 dias). Pegue o `id` de um backup `ready` e use [Restaurar como novo](/api-reference/backups/restore-as-new) para ter o projeto de volta, com outro ID. Os bancos excluídos vêm em `deletedDatabases` (7 dias); restaurá-los como um banco novo é só pelo painel. Vale com a chave de leitura.

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`invalid_api_key`](/errors#param-invalid-api-key) | 401 | Confira o cabeçalho `Authorization: Bearer cube_…`. |
| [`rate_limit_exceeded`](/errors#param-rate-limit-exceeded) | 429 | Espere o tempo do `Retry-After`. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
