---
title: "Baixar o backup"
openapi: "GET /projects/{id}/backups/{backupId}/download"
description: "O .zip do backup, pelo link de 5 minutos."
---

O `.zip` tem os arquivos do projeto sem as dependências, como na hora do backup. Dá para enviar de novo como um projeto novo ou com [Enviar novo código](/api-reference/projects/upload-code).
