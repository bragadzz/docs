---
title: "Trocar para onde o domínio vai"
openapi: "PATCH /projects/{id}/domains/{domainId}"
description: "Faça o domínio redirecionar para outro do site, ou abrir o site direto."
---

Para inverter o `www` (a raiz passa a levar ao `www`), mande `{ "redirectTo": "www.loja.com.br" }` no domínio da raiz: no mesmo pedido, o `www` passa a abrir o site. O redirecionamento é um `308` que mantém o caminho (`/produtos?x=1`).

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`invalid_redirect`](/errors#param-invalid-redirect) | 422 | Escolha outro domínio deste site que abre o site direto. |
| [`not_found`](/errors#param-not-found) | 404 | Confira o `id` do site e o `domainId` em [Listar domínios do site](/api-reference/domains/list). |
| [`insufficient_scope`](/errors#param-insufficient-scope) | 403 | A chave não tem a permissão da rota (`requiredScope` diz qual): marque em Chaves de API › Editar permissões. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
