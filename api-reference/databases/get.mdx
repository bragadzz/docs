---
title: "Ver um banco de dados"
openapi: "GET /databases/{id}"
description: "Um banco de dados, com o status, a memória e o disco de agora."
---

Use o `status` para saber se o banco já aceita conexões: `starting` é o banco que acabou de subir e ainda está preparando os dados; `running` é pronto. Parado, o `usage` vem `null`.

## Erros comuns

| Código | HTTP | O que fazer |
| --- | --- | --- |
| [`not_found`](/errors#param-not-found) | 404 | Confira o `id` em [Listar bancos de dados](/api-reference/databases/list): o banco não existe ou não é da sua conta. |
| [`invalid_api_key`](/errors#param-invalid-api-key) | 401 | Confira o cabeçalho `Authorization: Bearer cube_…`. |

Todos os códigos, com o formato do erro, em [Códigos de erro](/errors).
